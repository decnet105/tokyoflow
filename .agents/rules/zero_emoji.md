# Universal Zero Emoji Policy

## Strict Prohibition
- Under no circumstances should any emojis be used or generated anywhere in this project.
- This rule applies to:
  1. All chat interactions, agent replies, and explanations.
  2. All YouTube titles, descriptions, tags, and metadata files.
  3. Video generation code, Pillow canvas drawings, slide graphics, and thumbnails.
  4. Audio scripts and prompt templates.
  5. Documentation, logs, READMEs, and git commits.

## Alternative Formatting
- Use standard text bullets: `- `, `* `, `1. `, `2. `
- Use standard text brackets: `[JLPT N5]`, `【JLPT N4】`, `(EP.01)`
- Use standard section headers: `#`, `##`, `###`
- Never substitute emojis for bullet points, headers, or decorative symbols.
