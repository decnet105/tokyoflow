# TokyoFlow 日语实景精讲 • 教学方法论与实景架构蓝图 (中文版)

## 一、 核心教学理念：场景驱动（Use-Case Driven）
告别死板、枯燥的传统语法教科书，TokyoFlow 带你潜入东京最真实的日常现场：
- 山手线报站、地铁换乘与精算机补票全流程
- 7-Eleven / 全家便利店收银台秒回口诀（袋子、加热、积分卡）
- 居酒屋生啤开场与顶级拉面食券机定制口诀
- 秋叶原手办免税退税与银座精品试衣口语
- NHK 当季热点新闻与全网流行语深度拆解

---

## 二、 双轨闭环教学体系
1. **16:9 场景深度精讲大班课 (1080p)**
   - 沉浸式情境导入，还原真实店员语速与环境背景音；
   - 深度拆解核心语法、助词用法与敬语/常体切换；
   - 剖析日本本土潜规则（如委婉表达与读空气文化）。
2. **9:16 声带肌肉跟读短视频 (<60s)**
   - 同步跟读 Nanami 东京标准原声，训练声带发音肌肉记忆；
   - 严格对齐东京声调音高（Pitch Accent）与语速节奏；
   - 形成 0.5 秒脱口而出的本能反应。
