### KEY JAPANESE SENTENCE:
- ロボットが、料理を運びます。
- (Robotto ga, ryouri o hakobimasu.)
- Meaning: "A robot server delivers dishes to the tables."

### VOCABULARY & GRAMMAR BREAKDOWN:
1. ロボット (robotto) = Robot
2. 料理 (ryouri) = Food / Dishes / Cuisine
3. 運びます (hakobimasu) = Carries / Delivers (Polite present form of the JLPT N5 verb 'hakobu')
