## Description
NEVER MISS JAPAN MAIL
IN 30 SECONDS!
Japanese Phrase: 不在票が入っていたので、再配達をお願いします。 (Fuzaihyou ga haitte ita node, sai-haitatsu o onegai shimasu.)
English: I received a missed delivery slip, please redeliver.
Rule: Use 'node' to give polite reasons when speaking to customer service representatives in Japan!

VOCABULARY:
- 不在票が (ふざいひょうが) : Missed delivery slip
- 入っていたので、 (はいっていたので) : Was left, so
- 再配達を (さいはいたつを) : Redelivery
- お願いします (おねがいします) : Please
