## Description
ORDER COFFEE IN TOKYO
IN 30 SECONDS!
Japanese Phrase: アイスラテを豆乳に変更で、お持ち帰りお願いします。 (Aisu rate o tounyuu ni henkou de, omochikaeri onegai shimasu.)
English: Iced latte with soy milk substitution, to go please.
Rule: Say 'omochikaeri de' for to-go orders to get the 8% reduced food tax rate in Japan!

VOCABULARY:
- アイスラテを (あいすらてを) : Iced latte
- 豆乳に (とうにゅうに) : To soy milk
- 変更で、 (へんこうで) : Change,
- お持ち帰り (おもちかえり) : Takeout
- お願いします (おねがいします) : Please
