## Description
BOOK SHINKANSEN TICKETS
IN 30 SECONDS!
Japanese Phrase: 京都までの指定席、富士山側の窓側をお願いします。 (Kyouto made no shiteiseki, Fujisan-gawa no madogawa o onegai shimasu.)
English: Reserved seat to Kyoto with Mt. Fuji window view, please.
Rule: Always ask for 'Fujisan-gawa' (Seat E) on Tokaido Shinkansen trains for breathtaking Mt. Fuji views!

VOCABULARY:
- 京都までの (きょうとまでの) : To Kyoto
- 指定席、 (していせき) : Reserved seat,
- 富士山側の (ふじさんがわの) : Mt. Fuji side
- 窓側を (まどがわを) : Window seat
- お願いします (おねがいします) : Please
