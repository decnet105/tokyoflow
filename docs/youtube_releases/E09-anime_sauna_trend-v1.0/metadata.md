### KEY JAPANESE SENTENCE:
- アニメの会社が、新しいサウナを作りました。
- (Anime no kaisha ga, atarashii sauna o tsukurimashita.)
- Meaning: "An anime company has made a brand new sauna!"

### VOCABULARY & GRAMMAR BREAKDOWN:
1. アニメ (anime) = Animation / Anime
2. 会社 (kaisha) = Company / Studio
3. 新しい (atarashii) = New (i-adjective)
4. サウナ (sauna) = Sauna
5. 作りました (tsukurimashita) = Made / Built (Past polite form of the JLPT N5 verb 'tsukuru')
