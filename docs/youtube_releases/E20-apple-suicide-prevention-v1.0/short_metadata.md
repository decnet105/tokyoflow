REQUEST BY PM TAKAIICHI
Japanese Phrase: 高市首相はAppleに要請しました。 (Takaiichi shushou wa Appuru ni yousei shimashita.)
English: Prime Minister Takaiichi requested Apple.
Rule: Use 'に' to indicate the recipient of a request or action. This is a common structure in polite Japanese.
