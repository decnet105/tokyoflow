## 四、 iOS App 端增长战略与功能落地

在冷启动与放量增长阶段，App 端采取 **“极低门槛、极高体验、强社交激励”** 策略：

### 1. 100% 免费全功能开放 (Zero-Friction Access)
* **全级别词库与发音**：JLPT N5-N1 全量词汇（覆盖初中毕业阅读量）与 4,170 个原生音频全部免费开放。
* **全量东京场景**：电车换乘、便利店、居酒屋、秋叶原、药妆店等所有关卡 0 门槛解锁。
* **无限制 AI 复习**：移除单日复习限制，支持无限次 SM-2 记忆算法复习与弱点追踪。

### 2. 「次はどこへ行く？（Next 目的地）」动态 Generative UI 系统
* 用户可自由选择东京热门地标（涩谷、秋叶原、新宿、浅草、银座等）或输入自定义场景（如“台场高达”、“原宿可丽饼”）。
* **AI 即时动态生成**：现场高频金句（带声调、假名切换与原生发音）、实景演练对话、避坑礼仪指南与现场挑战任务。

### 3. YouTube 官方联动与社区激励
* 将付费强弹窗重构为 **「TokyoFlow 免费全能成长计划」**。
* 用户在 App 内一键关注 YouTube 官方频道（`TokyoFlow Japanese`），即刻领取 **500 Tokyo Points 积分** 与「早期共创先锋」勋章。
* 保留自愿型打赏赞助（“请喝咖啡” / “终身共创者”），为铁杆粉丝提供赞助入口。

### 4. 极致清爽的阅读与视觉体系
* 默认采用原生极简白（`Pure Clean`）与日式和纸护眼（`Washi Paper`）底色，彻底杜绝深色高对比背景造成的反光与字迹干扰。
