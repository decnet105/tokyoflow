This syllabus defines the authoritative vocabulary pools, grammar constraints, sentence structures, and pedagogical transformation rules for TokyoFlow Japanese video production, strictly aligned with authoritative Japanese language textbooks (Genki I & II, Minna no Nihongo I & II, Shin Kanzen Master, Try! Japanese).

## 1. JLPT N5 Production Syllabus (70% Quota)

### A. Strict Vocabulary Constraints
* Max Active Vocabulary Pool: ~800 foundational words.
* Daily Nouns: `会社` (kaisha), `店` (mise), `駅` (eki), `電車` (densha), `人` (hito), `友だち` (tomodachi), `映画` (eiga), `アニメ` (anime), `水` (mizu), `本` (hon), `今日` (kyou), `明日` (ashita), `日本` (nihon), `東京` (tokyo), `時間` (jikan), `お金` (okane).
* Core Verbs (Masu / Te / Dictionary forms only):
  - `行く` (iku), `来る` (kuru), `帰る` (kaeru) [Movement]
  - `見る` (miru), `聞く` (kiku), `話す` (hanasu), `言う` (iu) [Perception & Communication]
  - `食べる` (taberu), `飲む` (nomu), `買う` (kau) [Daily actions]
  - `作る` (tsukuru), `使う` (tsukau), `知る` (shiru), `待つ` (matsu), `入る` (hairu), `出る` (deru) [General actions]
* Core Adjectives:
  - い-Adjectives: `新しい` (atarashii), `古い` (furui), `大きい` (ookii), `小さい` (chiisai), `高い` (takai), `安い` (yasui), `面白い` (omoshiroi), `いい / よい` (ii).
  - な-Adjectives: `好き` (suki), `嫌い` (kirai), `上手` (jouzu), `下手` (heta), `有名` (yuumei), `静か` (shizuka).

### B. Allowed Grammar Patterns
1. `X は Y です / ではありません / でした` (Topic & Identity)
2. `〜ます / 〜ません / 〜ました / 〜ませんでした` (Polite present / past)
3. `X を Verb ます` (Direct object action: `アニメを見ます`, `新しい店を作りました`)
4. `X に / へ 行きます / 来ます` (Destination & Movement)
5. `X で Verb ます` (Location of action / Means: `東京で作ります`, `電車で行きます`)
6. `X が あります / います` (Existence of objects / people: `駅の前に新しいサウナがあります`)
7. `〜たいです / たくないです` (Desire: `見に行きたいです`, `買いたいです`)
8. `〜てください / ないでください` (Polite request: `これを見てください`)
9. `〜ています` (Action in progress / State: `今作っています`, `知っています`)
10. `〜てもいいですか` (Asking permission: `写真を撮ってもいいですか`)
11. `〜から` (Reason: `とても面白いですから、大人気です`)

### C. Downscaling Transformation Rules
* FORBIDDEN AT N5: Do NOT use abstract 4-Kanji Sino-Japanese compound words (e.g. `制作会社`, `新規事業展開`, `業務提携`, `開業を発表`).
* MANDATORY TRANSFORMATION:
  - Raw News: `アニメ制作会社がサウナの開業を発表した。`
  - N5 Pedagogical Script: `アニメの会社が、新しいサウナを作りました！` (An anime company made a new sauna!)
  - Breakdown: `アニメ` (Anime) + `会社` (Company) + `新しい` (New) + `作る` (To make).

## 2. JLPT N4 Production Syllabus (20% Quota)

### A. Key Vocabulary Pool (~1,500 words)
* `習慣` (shuukan), `事故` (jiko), `案内` (annai), `準備` (junbi), `連絡` (renraku), `相談` (soudan), `注意` (chuui), `出発` (shuppatsu), `都合` (tsugou).
* Verbs: `迎える` (mukaeru), `届ける` (todokeru), `助ける` (tasukeru), `壊れる` (kowareru), `遅れる` (okureru).

### B. Core Grammar Patterns
1. `〜んです / のです` (Explanatory nuance / Curiosity: `どうしてサウナを作ったんですか？`)
2. `〜すぎる` (Excessive degree: `人気がありすぎる`, `高すぎる`)
3. `〜たほうがいい / ないほうがいい` (Giving advice: `早く予約したほうがいいですよ`)
4. `〜ので / 〜のに` (Cause & Unexpected contrast: `人気なので混んでいます`)
5. `〜つもりです / 予定です` (Intentions: `来月東京へ行くつもりです`)
6. `〜たら / 〜なら / 〜ば / 〜と` (Conditionals: `東京へ行ったら、サウナに入ります`)
7. `〜てあげる / もらう / くれる` (Giving/receiving favors)
8. `〜ようにする / 〜ことになる` (Effort & result)
9. `受身 (Passive) 〜れる / られる` (e.g. `ファンに喜ばれた`)
10. `敬語 (Keigo) 入门`: `お + 动词stem + ください` (e.g. `お下がりください`, `お持ち帰りください`)

## 3. JLPT N3 Production Syllabus (10% Quota)

### A. Key Vocabulary Pool (~3,000 words & SNS Slang)
* `話題` (wadai), `反響` (hankyou), `展開` (tenkai), `体験` (taiken), `影響` (eikyou), `限定` (gentei), `トレンド` (trend).
* Slang & Netizen expressions: `バズる` (to go viral), `炎上する` (to get backlash), `神対応` (god-tier service), `エモい` (emotional/nostalgic).

### B. Core Grammar Patterns
1. `〜わけにはいかない / 〜わけがない` (Cannot afford to / Impossible)
2. `〜かねない / 〜かねる` (Might lead to / Unable to)
3. `〜を中心に / 〜をはじめ` (Centered around / Starting with)
4. `〜に基づいて / 〜をもとに` (Based on)
5. `〜に比べて / 〜に対して` (Compared to / In contrast to)
6. `〜最中に / 〜うちに` (In the middle of / While)
7. `〜っぽい / 〜らしい / 〜気味` (Tendency / Impression)
